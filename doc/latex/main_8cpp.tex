\doxysubsection{Detailed Description}
This program evaluates and compares four pseudo-\/random number generators\+:
\begin{DoxyEnumerate}
\item Linear Congruential Generator (\mbox{\hyperlink{classLCG}{LCG}})
\item \mbox{\hyperlink{classXorshift32}{Xorshift32}}
\item Middle Square Method
\item Mersenne Twister (std\+::mt19937)
\end{DoxyEnumerate}

The evaluation includes statistical tests and performance benchmarks.
